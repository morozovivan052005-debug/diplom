## 🏋️ Упражнения

### Описание

Справочник упражнений, которые можно использовать в тренировочных программах.

### Как добавить упражнение

1. Перейдите в `/admin` → **Упражнения** → **Create**
2. Заполните поля:

| Поле             | Пример                        | Описание                                     |
| ---------------- | ----------------------------- | -------------------------------------------- |
| **Name**         | Жим лежа                      | Название упражнения                          |
| **Description**  | Упражнение на грудь и трицепс | Описание техники или эффекта                 |
| **Muscle Group** | Грудь, трицепс                | Какие мышцы задействованы                    |
| **Equipment**    | Штанга, скамья                | Какое оборудование нужно                     |
| **Difficulty**   | Средний                       | Уровень сложности (Легкий, Средний, Сложный) |

### 📋 Примеры упражнений

#### Упражнение 1

- **Name:** Жим лежа
- **Description:** Базовое упражнение на грудь. Лежа на скамье, нужно поднимать штангу вверх от груди
- **Muscle Group:** Грудь, трицепс, передние дельты
- **Equipment:** Штанга, скамья для жима
- **Difficulty:** Средний

#### Упражнение 2

- **Name:** Приседания со штангой
- **Description:** Базовое упражнение на ноги. Приседать нужно так, чтобы бедро было параллельно полу
- **Muscle Group:** Ноги, ягодицы, квадрицепсы
- **Equipment:** Штанга, стойки для приседаний
- **Difficulty:** Средний

#### Упражнение 3

- **Name:** Становая тяга
- **Description:** Базовое упражнение на спину и ноги. Поднимать штангу с пола до уровня бедер
- **Muscle Group:** Спина, ноги, ягодицы
- **Equipment:** Штанга
- **Difficulty:** Сложный

## 💪 Программы тренировок

### Описание

Шаблоны тренировочных программ, которые система автоматически назначает пользователям на основе их целей.

### Как добавить программу

1. Перейдите в `/admin` → **Программы тренировок** → **Create**
2. Заполните поля:

| Поле               | Пример                                            | Описание                                                           |
| ------------------ | ------------------------------------------------- | ------------------------------------------------------------------ |
| **Name**           | Программа снижения веса (3 дня в неделю)          | Название программы                                                 |
| **Description**    | Интенсивная программа для активного сжигания жира | Описание программы                                                 |
| **Goal Type**      | lose_weight                                       | **Важно!** Должен совпадать с целью пользователя (см. список ниже) |
| **Difficulty**     | Средний                                           | Уровень сложности программы                                        |
| **Duration Weeks** | 12                                                | На сколько недель рассчитана программа                             |

### 🎯 Код целей (Goal Type)

**Эти коды должны совпадать с тем, что выбирает пользователь в профиле:**

| Код           | Описание             | Подходит для             |
| ------------- | -------------------- | ------------------------ |
| `lose_weight` | Снижение веса        | Похудение                |
| `maintain`    | Поддержание веса     | Сохранение текущей формы |
| `recomp`      | Рекомпозиция тела    | Сила + сжигание жира     |
| `gain_muscle` | Набор мышечной массы | Бодибилдинг              |

### 📋 Примеры программ

#### Программа 1: Снижение веса

- **Name:** Программа для похудения (3 дня/неделю)
- **Description:** Интенсивная кардио-силовая программа для активного сжигания калорий и жира
- **Goal Type:** `lose_weight`
- **Difficulty:** Высокий
- **Duration Weeks:** 12

#### Программа 2: Поддержание

- **Name:** Программа поддержания (2 дня/неделю)
- **Description:** Легкая поддерживающая программа для сохранения текущей формы
- **Goal Type:** `maintain`
- **Difficulty:** Легкий
- **Duration Weeks:** 52

#### Программа 3: Набор мышц

- **Name:** Программа набора массы (5 дней/неделю)
- **Description:** Силовая программа для максимального набора мышечной массы с интенсивными нагрузками
- **Goal Type:** `gain_muscle`
- **Difficulty:** Средний
- **Duration Weeks:** 16

## 🔗 Упражнения в программах

### Описание

Связывает упражнения с программами. Определяет порядок, день недели, подходы и повторения.

### Как добавить упражнение в программу

1. Перейдите в `/admin` → **Упражнения в программах** → **Create**
2. Заполните поля:

| Поле             | Пример                       | Описание                                              |
| ---------------- | ---------------------------- | ----------------------------------------------------- |
| **Program**      | Программа для похудения      | Выберите программу                                    |
| **Exercise**     | Жим лежа                     | Выберите упражнение                                   |
| **Day Number**   | 1                            | День недели (1=Пн, 2=Вт, ..., 7=Вс)                   |
| **Order In Day** | 1                            | Порядок упражнения в день (1-первое, 2-второе и т.д.) |
| **Sets**         | 3                            | Количество подходов                                   |
| **Reps**         | 8-12                         | Диапазон повторений (например "8-12" или "10")        |
| **Notes**        | Отдых 60 сек между подходами | Дополнительные инструкции                             |

### 📋 Примеры

#### Пример 1: День 1 - Грудь

- **Program:** Программа для похудения
- **Exercise:** Жим лежа
- **Day Number:** 1
- **Order In Day:** 1
- **Sets:** 4
- **Reps:** 8-10
- **Notes:** Классический жим. Опускать в течение 2 сек, поднимать 1 сек

#### Пример 2: День 1 - Спина (второе упражнение)

- **Program:** Программа для похудения
- **Exercise:** Тяга в наклоне
- **Day Number:** 1
- **Order In Day:** 2
- **Sets:** 3
- **Reps:** 10-12
- **Notes:** Отдых 90 сек между подходами

#### Пример 3: День 2 - Ноги

- **Program:** Программа для похудения
- **Exercise:** Приседания со штангой
- **Day Number:** 2
- **Order In Day:** 1
- **Sets:** 5
- **Reps:** 5-8
- **Notes:** Тяжелое упражнение. Приседать глубоко, спину держать прямой

## 🎯 Цели

### Описание

Личные цели пользователя по весу, проценту жира, мышечной массе и т.д.

### Как добавить цель пользователю

1. Перейдите в `/admin` → **Цели** → **Create**
2. Заполните поля:

| Поле              | Пример                | Описание                         |
| ----------------- | --------------------- | -------------------------------- |
| **User**          | admin@example.com     | Выберите пользователя            |
| **Goal Type**     | weight                | Тип цели (вес, жир, мышцы)       |
| **Current Value** | 85.5                  | Текущее значение                 |
| **Target Value**  | 75.0                  | Целевое значение                 |
| **Unit**          | кг                    | Единица измерения                |
| **Deadline**      | 2026-07-21            | Когда достичь цель (опционально) |
| **Notes**         | Нужно похудеть к лету | Комментарии (опционально)        |

### 🎯 Типы целей

| Тип         | Единица | Пример    | Описание            |
| ----------- | ------- | --------- | ------------------- |
| `weight`    | кг      | 80 → 75   | Цель по весу        |
| `body_fat`  | %       | 28 → 22   | Процент жира        |
| `muscle`    | кг      | 60 → 65   | Мышечная масса      |
| `strength`  | кг      | 100 → 150 | Сила (вес при жиме) |
| `endurance` | км      | 5 → 10    | Выносливость        |

### 📋 Примеры целей

#### Цель 1: Похудение

- **User:** admin@example.com
- **Goal Type:** weight
- **Current Value:** 85.5
- **Target Value:** 75.0
- **Unit:** кг
- **Deadline:** 2026-10-21 (3 месяца)
- **Notes:** Основная цель - сбросить 10.5 кг для улучшения здоровья

#### Цель 2: Снижение жира

- **User:** admin@example.com
- **Goal Type:** body_fat
- **Current Value:** 28
- **Target Value:** 20
- **Unit:** %
- **Deadline:** 2026-12-21 (9 месяцев)
- **Notes:** Целевой процент жира для пресса

#### Цель 3: Набор мышц

- **User:** admin@example.com
- **Goal Type:** muscle
- **Current Value:** 60
- **Target Value:** 67
- **Unit:** кг
- **Deadline:** 2026-12-21 (9 месяцев)
- **Notes:** Набрать 7 кг качественной мышечной массы

## 📊 Логирование прогресса

### Описание

Записи о достижениях пользователя - вес, жир, мышцы в определенные дни.

### Как просмотреть логирование

1. Перейдите в `/admin` → **Логирование прогресса**
2. Видите все записи пользователей
3. Можете отредактировать или удалить запись

### Как добавить запись (если нужно вручную)

1. Нажмите **Create**
2. Заполните поля:

| Поле         | Пример            | Описание                  |
| ------------ | ----------------- | ------------------------- |
| **User**     | admin@example.com | Кому принадлежит запись   |
| **Goal**     | weight            | Какую цель логируем       |
| **Log Date** | 2026-04-21        | Дата логирования          |
| **Value**    | 82.5              | Значение на эту дату      |
| **Notes**    | После тренировки  | Комментарии (опционально) |

### 📋 Примеры логирования

#### Запись 1: Вес

- **User:** admin@example.com
- **Goal:** weight (цель 1 - похудение)
- **Log Date:** 2026-04-21
- **Value:** 82.5
- **Notes:** Утром, натощак, после сна

#### Запись 2: Жир

- **User:** admin@example.com
- **Goal:** body_fat (цель 2 - снижение жира)
- **Log Date:** 2026-04-21
- **Value:** 26.5
- **Notes:** Измерено штангенциркулем

#### Записи на неделю

```
Дата        | Вес   | Жир  | Мышцы | Примечание
2026-04-14  | 84.0  | 28.0 | 60.5  | Начало недели
2026-04-17  | 83.2  | 27.5 | 60.8  | Середина
2026-04-21  | 82.5  | 26.5 | 61.2  | Конец недели
```

## 👤 Профили

### Описание

Личные данные пользователя (рост, вес, возраст, уровень активности, цель).

### Информация в профиле

| Поле                 | Пример                  | Описание                 |
| -------------------- | ----------------------- | ------------------------ |
| **User**             | admin@example.com       | Ссылка на пользователя   |
| **Height CM**        | 180                     | Рост в сантиметрах       |
| **Weight KG**        | 82.5                    | Вес в килограммах        |
| **Age Years**        | 30                      | Возраст в годах          |
| **Is Male**          | ✓ (отмечено)            | Пол: мужской или женский |
| **Activity Level**   | moderate                | Уровень активности       |
| **Goal Code**        | lose_weight             | Цель по весу/телу        |
| **Goal**             | Похудеть к лету         | Комментарий к цели       |
| **Assigned Program** | Программа для похудения | Назначенная программа    |

### Уровни активности

| Код         | Название        | Описание                   | Множитель BMR |
| ----------- | --------------- | -------------------------- | ------------- |
| `sedentary` | Малоподвижный   | Сидячая работа, нет спорта | 1.2           |
| `light`     | Лёгкая нагрузка | 1-3 тренировки в неделю    | 1.375         |
| `moderate`  | Умеренная       | 3-5 тренировок в неделю    | 1.55          |
| `high`      | Высокая         | 5-6 тренировок в неделю    | 1.725         |
| `very_high` | Очень высокая   | Ежедневные тренировки      | 1.9           |

## 👥 Пользователи

### Описание

Управление аккаунтами пользователей и правами администратора.

### Как добавить администратора

1. Перейдите в `/admin` → **Пользователи**
2. Найдите пользователя
3. Отметьте **Is Admin** ✓
4. Сохраните

### Поля

| Поле              | Описание                                |
| ----------------- | --------------------------------------- |
| **Email**         | Email пользователя (уникальный)         |
| **Password Hash** | Хешированный пароль (не редактировать!) |
| **Is Admin**      | Флаг администратора                     |
| **Created At**    | Дата регистрации (автоматически)        |

## 🔄 Процесс настройки системы (пошагово)

### Шаг 1: Добавить упражнения

1. Перейти в `/admin` → **Упражнения** → **Create**
2. Добавить 5-10 упражнений (жим, приседания, тяга и т.д.)

### Шаг 2: Создать программы

1. Перейти в `/admin` → **Программы тренировок** → **Create**
2. Создать 4 программы:
   - Для похудения (`lose_weight`)
   - Для поддержания (`maintain`)
   - Для рекомпозиции (`recomp`)
   - Для набора (`gain_muscle`)

### Шаг 3: Добавить упражнения в программы

1. Перейти в `/admin` → **Упражнения в программах** → **Create**
2. Добавить упражнения для каждого дня каждой программы
3. Указать подходы, повторения, дни недели

### Шаг 4: Создать цели для пользователей

1. Перейти в `/admin` → **Цели** → **Create**
2. Добавить цели для тестовых пользователей

### Шаг 5: Пользователи сами логируют прогресс

1. Пользователи откроют `/calendar`
2. Кликнут на день
3. Добавят значение для целей

## 💡 Советы

### ✅ Что нужно делать

- Используйте понятные названия упражнений на русском
- Указывайте подробные описания и заметки
- Добавляйте несколько примеров программ
- Проверяйте, что Goal Type программы совпадает с целью пользователя
- Регулярно добавляйте новые упражнения для разнообразия

### ❌ Чего не нужно делать

- Не используйте Goal Type, которых нет в коде профиля (они не сработают)
- Не переводите коды целей (lose_weight, а не "похудение")
- Не добавляйте упражнения с одинаковыми названиями
- Не оставляйте программы без упражнений

## 🔍 Проверка функциональности

### Проверьте, что:

1. ✅ В профиле видна назначенная программа

3. ✅ Админ может редактировать все данные
4. ✅ При создании цели совпадает Goal Type и Assigned Program Goal Type
