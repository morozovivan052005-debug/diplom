## 🚀 Как это работает

### Для пользователя:

1. Войти в профиль
2. Нажать "Перейти к календарю"
3. Выбрать месяц
4. Кликнуть на день
5. Заполнить форму с целью и значением
6. Сохранить

### Для администратора:

1. Перейти в `/admin`
2. Раздел "Цели"
3. Create → заполнить форму:
   - Пользователь
   - Тип цели (weight, body_fat, muscle)
   - Текущее значение
   - Целевое значение
   - Единица (кг, %, см)
   - Срок

## 📊 Новые таблицы БД

### `goals` (таблица целей)

| Поле          | Тип      | Описание                    |
| ------------- | -------- | --------------------------- |
| id            | INT      | первичный ключ              |
| user_id       | INT      | ID пользователя             |
| goal_type     | STR      | тип цели (weight, body_fat) |
| current_value | FLOAT    | текущее значение            |
| target_value  | FLOAT    | целевое значение            |
| unit          | STR      | единица (кг, %)             |
| deadline      | DATETIME | срок достижения             |
| notes         | TEXT     | комментарии                 |

### `progress_logs` (таблица логирования)

| Поле     | Тип   | Описание                    |
| -------- | ----- | --------------------------- |
| id       | INT   | первичный ключ              |
| user_id  | INT   | ID пользователя             |
| goal_id  | INT   | ID цели                     |
| log_date | DATE  | дата логирования            |
| value    | FLOAT | зарегистрированное значение |
| notes    | TEXT  | комментарии                 |

## 🔗 API Endpoints

### GET `/api/calendar/<year>/<month>`

Получить все логирования за месяц

```json
Response: {
  "1": [{goal_id: 1, value: 75.5, unit: "кг", ...}],
  "5": [{goal_id: 2, value: 20, unit: "%", ...}]
}
```

### POST `/api/log-progress`

Добавить или обновить логирование

```json
Request: {
  "log_date": "2026-04-21",
  "goal_id": 1,
  "value": 75.5,
  "notes": "После тренировки"
}
Response: {"id": 123, "status": "created"}
```

### DELETE `/api/delete-log/<id>`

Удалить запись логирования

```json
Response: {"status": "deleted"}
```
