## 📋 Структура новых функций

### Новые таблицы БД:

- **goals** — цели пользователя (вес, жир, мышцы)
- **progress_logs** — записи логирования с датами

### Новые маршруты:

- `GET /calendar` — страница календаря
- `GET /api/calendar/<year>/<month>` — API для получения логирования
- `POST /api/log-progress` — добавить/обновить запись
- `DELETE /api/delete-log/<id>` — удалить запись

### Новые представления в админ-панели:

- **Цели** — создание/редактирование целей (`/admin/goal/`)
- **Логирование прогресса** — просмотр записей (`/admin/progresslog/`)

## 🎯 Как использовать

### Администратор:

1. Перейдите в `/admin`
2. Раздел "Цели" → Create
3. Выберите пользователя и заполните:
   - Тип цели: `weight`, `body_fat`, `muscle`, и т.д.
   - Текущее значение: начальное значение
   - Целевое значение: то, к чему стремиться
   - Единица: кг, %, см
   - Срок: дата достижения (опционально)

### Пользователь:

1. Откройте профиль → "Перейти к календарю"
2. Кликните на любой день
3. Выберите цель и введите значение
4. Нажмите "Сохранить"

## 🆘 Часто задаваемые вопросы

**Q: Можно ли редактировать существующее логирование?**
A: Да, кликните на день, где есть запись, и отредактируйте значение.

**Q: Как удалить запись?**
A: Откройте день, нажмите кнопку "Удалить" в модальном окне.

**Q: Что произойдет, если я добавлю две записи на один день для одной цели?**
A: Вторая запись обновит первую (система оставляет только одну запись в день на цель).

**Q: Видят ли цели другие пользователи?**
A: Нет, каждый пользователь видит только свои цели и логирование.
