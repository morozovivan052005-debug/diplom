# Новые функции: Календарь прогресса и управление целями

## 📋 Что добавлено

### 1. **Модели целей и логирования прогресса**

- **Goal** — таблица целей по весу/телу (зависит от профиля)
- **ProgressLog** — таблица логирования прогресса с датами

### 2. **Интерактивный календарь прогресса**

- Полноценный календарь с навигацией по месяцам
- Выбор месяца/года через месячный селектор
- Кнопка "Сегодня" для быстрого перехода на текущую дату
- Кнопки "Назад/Вперед" для навигации

### 3. **Логирование достижений**

- Клик по дню открывает модальное окно для добавления логирования
- Выбор цели и вввод значения
- Опциональные заметки к каждому логированию
- Отредактирование или удаление записей

### 4. **Админ-панель управления целями**

- **Цели** — управление целями пользователей (тип, текущее значение, целевое значение)
- **Логирование прогресса** — просмотр и редактирование всех записей логирования

## 🚀 Как использовать

### Для пользователей:

1. **Перейти на календарь:**
   - Из профиля нажать кнопку "Перейти к календарю"
   - URL: `/calendar`

2. **Логировать прогресс:**
   - Кликнуть на день в календаре
   - Выбрать цель (например, "weight")
   - Ввести значение (вес в кг)
   - Нажать "Сохранить"

3. **Навигация по месяцам:**
   - Использовать кнопки "Назад/Вперед"
   - Или выбрать месяц в селекторе
   - Или нажать "Сегодня" для текущей даты

### Для администраторов:

1. **Создание целей:**
   - Перейти в админ-панель `/admin`
   - Раздел "Цели"
   - Нажать "Create" (или Edit для существующих)
   - Заполнить:
     - **Пользователь** — выбрать пользователя
     - **Тип цели** — например, `weight` (для веса), `body_fat` (процент жира)
     - **Текущее значение** — начальное значение
     - **Целевое значение** — то, к чему стремиться
     - **Единица измерения** — кг, %, см и т.д.
     - **Срок** — до какой даты (опционально)
     - **Заметки** — дополнительная информация

2. **Просмотр логирования:**
   - Раздел "Логирование прогресса"
   - Фильтрация по пользователю или дате
   - Редактирование или удаление записей

## 📊 API маршруты

- **GET `/calendar`** — страница календаря
- **GET `/api/calendar/<year>/<month>`** — получить логирование за месяц (JSON)
- **POST `/api/log-progress`** — добавить/обновить логирование
  ```json
  {
    "log_date": "2026-04-21",
    "goal_id": 1,
    "value": 75.5,
    "notes": "После тренировки"
  }
  ```
- **DELETE `/api/delete-log/<log_id>`** — удалить логирование

## 🎨 Визуальное обозначение

На календаре:

- **Светло-голубой фон** — сегодня
- **Зеленый фон** — дни с логированием
- **Цветные бейджи** — значения с типом цели:
  - Синий — weight (вес)
  - Красный — body_fat (жир)
  - Голубой — muscle (мышцы)

## 📝 Примеры использования API

### Добавить логирование

```bash
curl -X POST http://localhost:5000/api/log-progress \
  -H "Content-Type: application/json" \
  -d '{
    "log_date": "2026-04-21",
    "goal_id": 1,
    "value": 75.5,
    "notes": "Утром, натощак"
  }'
```

### Получить логирование за месяц

```bash
curl http://localhost:5000/api/calendar/2026/4
```

## ⚠️ Важные замечания

1. Цели должны быть созданы администратором в админ-панели
2. Каждое логирование привязано к цели
3. Один пользователь может иметь несколько целей
4. Для одной цели в один день может быть только одно логирование (при повторном добавлении обновляется)
5. Календарь показывает только логирования текущего пользователя

## 🐛 Решение проблем

**Календарь не показывает дни с логированием:**

- Убедитесь, что цели созданы в админ-панели
- Проверьте, что goal_id совпадает с ID цели

**Не видна кнопка "Перейти к календарю":**

- Очистите кэш браузера (Ctrl+Shift+Delete)
- Перезагрузите страницу профиля
